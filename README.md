# Weather Image Classification Using CNN

## Project Overview
This project uses a Convolutional Neural Network (CNN) to classify weather images into different weather categories using Deep Learning.

## Technologies Used
- Python
- Google Colab
- PyTorch
- Torchvision
- Matplotlib
- NumPy

## Dataset
The dataset contains five weather categories:

1. Cloudy
2. Foggy
3. Rainy
4. Shine
5. Sunrise

## Project Workflow
1. Dataset loading
2. Data preprocessing
3. Image resizing and normalization
4. Training and testing data splitting
5. CNN model development
6. Model training
7. Data augmentation
8. Model evaluation
9. Prediction and visualization

## Model Evaluation

| Model | Accuracy |
|---|---:|
| Baseline CNN | 83.11% |
| CNN with Data Augmentation | 84.44% |

Augmented Model F1-Score: 83.68%

## Image Configuration
- Image Size: 128 x 128
- Batch Size: 32
- Number of Classes: 5

## How to Run
1. Open the notebook using Google Colab.
2. Upload or mount the dataset.
3. Execute the notebook cells sequentially.
4. Observe the training results and predictions.

## Project Objective
To develop a deep learning-based image classification system capable of identifying different weather conditions from images.
